# Lit-check: D1-I8 — Cross-layer dispatch/combine software pipelining

## Idea recap
Two-layer rolling pipeline: layer ℓ+1's (attention+router+dispatch) overlapped with ℓ's (combine+expert GEMM). Reduces *exposed* a2a time, not byte volume.

## Keywords searched
- MoE communication compute overlap Lancet Comet 2024-2025
- cross-layer pipelining MoE inference
- DeepEP overlap dispatch

## Top candidates considered (all verified)
1. **Lancet** (Jiang et al., MLSys 2024, arXiv:2404.19429, verified=YES via D1 trace) — whole-graph computation-communication overlap; training-side.
2. **Comet** (Zhang et al., 2025, arXiv:2502.19811, verified=YES via D1 trace) — fine-grained MoE comm-comp overlap; training+inference relevant. **Direct competitor.**
3. **FAST** (arXiv:2505.09764, verified=YES via D1 trace) — efficient a2a scheduler; balanced transfers under skew.
4. **DeepEP** — production fused dispatch+combine with double buffering; achieves overlap operationally.
5. **NCCL EP** (arXiv:2603.13606, verified=YES via D5 trace) — unified MoE comm API supporting LL/HT modes.

## Closest 3 priors + differences
- **Comet** — closest direct competitor: fine-grained MoE overlap. **Diff**: D1-I8 is *cross-layer* specifically; Comet is intra-layer fine-grained. Need to confirm differentiation by reading Comet carefully.
- **Lancet** — training-side whole-graph overlap; inference applicability unclear. **Diff**: D1-I8 is inference + scheduler-only.
- **DeepEP** — operational solution; not academic paper, but is the deployed substrate.

## Has been published? **完全 (after GPT QC reveal)**
GPT QC surfaced 3 critical priors Claude missed:
- **LongCat-Flash Technical Report / ScMoE + SBO** (Meituan, Sept 2025, arXiv:2509.01322, verified=YES) — **Shortcut-connected MoE explicitly designed to enlarge the computation-communication overlap window during inference**. Direct kill of D1-I8 inference-cross-layer angle.
- **EPS-MoE** (Qian et al., Oct 2024, arXiv:2410.12247, verified=YES) — Expert Pipeline Scheduler dynamically overlaps MoE FFN compute with communication; +52.4% prefill throughput.
- **FlashMoE / FlashDMoE** (Aimuyo et al., June 2025, arXiv:2506.04667, verified=YES) — single-kernel fused MoE forward with fine-grained dispatch/compute/combine pipelining.

## Collision rating: **完全撞**
