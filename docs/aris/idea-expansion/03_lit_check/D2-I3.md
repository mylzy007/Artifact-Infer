# Lit-check: D2-I3 — Phase-asymmetric top-K (K_decode<K_prefill)

## Idea recap
Phase-structural `K_decode=4, K_prefill=8` based on launch-bound argument; renormalization post-truncation.

## Keywords searched
- per-token variable K MoE inference 2024-2025 (D1+D2 traces)
- decode K reduction launch overhead

## Top candidates (all verified)
1. **SMIDT** (AAAI'26) — dynamic Top-K + prefill/decode disagg.
2. **SERE** (arXiv:2602.07616) — similarity-based expert re-routing during batch decoding.
3. **OEA / Opportunistic Expert Activation** (arXiv:2511.02237) — batch-aware decode routing.
4. **Adaptive Gating** (Li et al., EMNLP'23, arXiv:2310.07188, verified=YES via D1 collision trace) — earliest per-token variable K.
5. **DA-MoE** (arXiv:2409.06669, verified=YES via D1 collision trace) — per-token K via attention importance.
6. **DTop-p MoE / Sparsity-Controllable** (arXiv:2512.13996, verified=YES via D1 collision trace) — PI-controller-driven dynamic K.
7. **AdaMoE** (arXiv:2406.13233) — null-expert variable K.

## Closest 3 priors + differences
- **SMIDT** — explicit prefill/decode disaggregation with dynamic K. **Diff**: SMIDT is workload-dynamic K; D2-I3 is *phase-structural* (always K_decode<K_prefill). Thin differentiator.
- **Adaptive Gating** — per-token variable K from 2023. **Diff**: not phase-structural.
- **DTop-p** — sparsity-controllable cumulative probability. **Diff**: probability threshold vs fixed K_decode.

## Has been published? **largely**
The per-token / per-phase variable K space is heavily occupied (≥7 priors). Phase-structural is a thin differentiator over SMIDT-style dynamic K.

## Collision rating: **完全撞**
D1 collision check already found 3 missed priors (Adaptive Gating, DA-MoE, DTop-p). Adding SMIDT, SERE, OEA, AdaMoE, this is one of the most saturated topic areas in the pool.

## Additional missed priors (from GPT collision QC, all verified=YES)
- **Expert Choice Routing** (Zhou et al., NeurIPS 2022, arXiv:2202.09368) — variable experts per token via top-k-tokens; the foundational variable-K mechanism.
- **DirMoE** (Vahidi et al., ICLR 2026, arXiv:2602.09001) — Bernoulli expert selection + direct sparsity penalty controlling expected active experts.
- **DynaMoE** (Gülmez, 2026, arXiv:2603.01697) — dynamic token-level expert activation + layer-wise adaptive capacity (6 scheduling strategies including phase-like distribution).
- **Dynamic MoE** (Guo et al., ICLR 2025, arXiv:2405.14297) — auto-tuning per-token K during training.

Adding these makes variable/dynamic K one of the most heavily occupied topic areas in our search (≥11 close priors).

## Conclusion: **放弃**
GPT QC reinforces: "K_decode=4, K_prefill=8 + renorm" is a degenerate special case of established dynamic/adaptive K work (Expert Choice, DirMoE, DynaMoE, Dynamic MoE, Adaptive Gating, DA-MoE, DTop-p, SMIDT, AdaMoE). Only narrow salvage: "post-hoc serving policy + accuracy-risk knob conditioned on L*/launch-bound diagnosis" — not a routing contribution. Drop.
