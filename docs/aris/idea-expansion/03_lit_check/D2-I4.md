# Lit-check: D2-I4 — Phase-asymmetric bi-modal placement

## Idea recap
Two placement plans (prefill: worst-peer bytes objective; decode: remote-rank-hit objective) over shared physical replicas; pointer swap at boundary.

## Keywords searched
- MoE expert placement bi-modal phase aware 2024-2025
- expert placement minimax (D1 collision)
- topology-aware placement

1. **Cluster Topology-Driven Placement** (arXiv:2508.09229) — ILP topology placement, single-objective.
2. **MoETuner** (arXiv:2502.06643) — ILP balance + routing.
3. **GRACE-MoE** (arXiv:2509.25041, verified=YES this trace) — grouping + replication + locality routing.

## Closest 3 priors + differences
- **Patterns behind Chaos** — explicit *prefill-aware* placement. **Diff**: D2-I4 has *two plans + phase swap*, not one prefill-tuned plan.
- **GRACE-MoE** — grouping + replication with locality routing. **Diff**: single plan; not phase swap.
- **MoETuner** — single-objective ILP placement. **Diff**: D2-I4 has two objectives + swap.

## Has been published? **no** (specifically for two-plan phase-swap)
Single-plan static placement is multiply published. The two-plan + atomic pointer swap is not directly published.

## Collision rating: **接近但有差异**
ILP placement is crowded; two-plan-swap differentiation is the *Jaccard ≥0.2* falsification claim. If two ILP solutions coincide, idea collapses.

## Conclusion: **可做 / 需调整**
Defensible if (i) explicit Jaccard ≥0.2 between two ILP solutions (already in spec), (ii) scope honestly to `ep_ht`-style point-to-point decode runtimes. The cross-dimension reuse of D1-I5's prefill objective is necessary positioning.
