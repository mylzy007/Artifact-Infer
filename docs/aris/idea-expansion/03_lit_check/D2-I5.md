# Lit-check: D2-I5 — L_recv-gated continuous phase detection (per-layer)

## Idea recap
Per-layer per-step `L_recv_ℓ > L*_ℓ` condition replaces binary phase tag; offline-calibrated per-layer threshold.

## Keywords searched
- DuoServe-MoE / SMIDT prefill decode (D2 trace)
- L_recv-aware MoE scheduling
- intra-GPU phase detection LLM

## Top candidates (all verified)
1. **DuoServe-MoE** (arXiv:2509.07379) — dual-phase MoE expert prefetch+cache; request-level granularity.
2. **SMIDT** (AAAI'26) — prefill/decode disagg with dynamic Top-K; instance-level.
3. **Nexus** (arXiv:2507.06608) — proactive intra-GPU disaggregation; dense LLM.
4. **MoE-Lens** (arXiv:2504.09345, verified existence) — resource-aware scheduler with phase distinction.
5. **DAOP** (arXiv:2501.10375) — data-aware offloading + predictive pre-calc one layer ahead.

## Closest 3 priors + differences
- **DuoServe-MoE** — dual-phase MoE scheduling. **Diff**: request-granularity prefetch vs per-layer per-step drop kernel selection.
- **SMIDT** — instance-level phase disagg. **Diff**: D2-I5 is intra-instance per-layer.
- **Nexus** — intra-GPU phase. **Diff**: dense LLM, not MoE.

## Has been published? **partial**
Phase-aware MoE serving is established (DuoServe-MoE, SMIDT). Per-layer L_recv-gated micro-switch with per-layer calibrated L*_ℓ is not directly published.

## Collision rating: **接近但有差异**
Per-layer granularity + L_recv-as-control-variable is the differentiator. GPT D2 QC already confirmed "structurally safe / distinguishable from DistServe-for-MoE".

## Conclusion: **可做**
Strongest D2 candidate. Required: explicit per-layer calibration procedure as part of the contribution + sharpen vs DuoServe-MoE lever differential.
