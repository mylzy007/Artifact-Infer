## Conclusion: **需调整 (reframe required)**
Salvage = NOT "new collective" (EP libraries own that), but **budgeted semantic collective**: API takes `B_bytes` + policy/quality objective and returns the best legal approximate MoE combine under budget. Rename: `BudgetedDispatchCombine` or `BudgetedAllToAllV` (not "reduce-scatter"; the math is a2a-V). Novelty hinges on one of:
- formal byte-budget contract with error bounds,
- router-score-aware degradation,
- unified lowering of drop/top-k/quant into one budget optimizer.
