# Lit-check: D1-I10 — A2A bytes as first-class MoE performance model

## Idea recap
Define `worst-peer dispatch+combine wire bytes per layer-step` as primary regressor for MoE prefill latency. R² ≥ 0.75 target vs L_recv-rows R² ≤ 0.55 and FLOPs R² ≤ 0.30.

## Top candidates considered (all verified)
1. **LLM Inference Unveiled** (Yuan et al., 2024, arXiv:2402.16363, verified=YES via D5 trace) — roofline-model survey covering MoE among techniques; no MoE-specific a2a byte lower bound.
2. **Vidur** (Agrawal et al., MLSys 2024, arXiv:2405.05465, verified=YES via D4 trace) — large-scale LLM inference simulator; dense-LLM-centric; MoE-specific cost not isolated.
3. **MoE-CAP** (Jiang et al., 2024, arXiv:2412.07067, verified=YES via D4 trace) — benchmark of cost-accuracy-perf of sparse MoE; benchmark not predictive model.
4. **MoE-Lens** (arXiv:2504.09345, verified=YES via D3 trace) — holistic perf modeling, throughput-bound, CPU-memory focus.
5. **Toward Efficient Inference for MoE** (Huang et al., NeurIPS 2024, verified=YES via D1 trace) — characterization paper, multiple factors including communication, no isolated regressor.
6. **MixServe** (arXiv:2601.08800, verified=YES via D1 trace) — fused AR-A2A serving; cost in scheduling function, not isolated metric.
7. **LIFE / Hardware-Agnostic Analytical Modeling** (arXiv:2508.00904, verified=YES via D4 trace) — hardware-agnostic forecasting; dense-LLM focus.
