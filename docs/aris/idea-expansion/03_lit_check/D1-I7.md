# Lit-check: D1-I7 — Per-token K_eff thinning by expected byte ROI

## Idea recap
Per-token `K_eff` chosen by score-gap rule (drop expert k if `score_k / score_1 < θ`). Reduces dispatch bytes (vs uniform K) at quality cost.

## Keywords searched
- MoE adaptive top-K dynamic routing token-adaptive 2024-2025
- AdaMoE / SMIDT / SERE dynamic K

## Top candidates considered (all verified)
1. **AdaMoE** (arXiv:2406.13233, verified=YES this trace) — token-adaptive routing with null experts; variable K via load-balancing loss. *Training* mechanism.
2. **SMIDT** (AAAI-26, verified=YES via D2 trace) — dynamic Top-K routing for MoE inference, prefill/decode disaggregated.
3. **SERE** (arXiv:2602.07616, verified=YES via D2 trace) — similarity-based expert re-routing for batch decoding; reroutes rather than thins.
4. **Capacity-Aware Inference** (arXiv:2503.05066, verified=YES via D1 trace) — capacity-aware token drop/reroute.
5. **Opportunistic Expert Activation** (arXiv:2511.02237, verified=YES via D2 trace) — batch-aware routing using already-resident experts.
6. **Dynamic top-K MoE routing** (arXiv:2403.07652, verified=YES via D5 trace) — confidence-based per-token expert allocation.

## Closest 3 priors + differences
- **SMIDT** — closest semantic neighbor: dynamic Top-K routing for inference. **Diff**: D1-I7 phrases it as *byte-ROI threshold* rather than capacity/load-driven; less novel for K-mechanism per se.
- **Dynamic Top-K (2403.07652)** — confidence-based variable K. **Diff**: similar score-gap rule; SAME mechanism class.
- **AdaMoE** — null experts give per-token variable K. **Diff**: D1-I7 is post-hoc threshold; AdaMoE is trained.

## Has been published? **largely (after GPT QC reveal)**
Per-token variable K is multiply published. GPT QC surfaced 3 more priors Claude missed:
- **Adaptive Gating in MoE LMs** (Li et al., EMNLP'23, arXiv:2310.07188, verified=YES) — earliest known per-token variable K via router probability.
- **DA-MoE** (Akhavan Aghdam et al., 2024, arXiv:2409.06669, verified=YES) — per-token K via attention-importance scoring.
- **DTop-p MoE / Sparsity-Controllable** (Jin et al., 2025, arXiv:2512.13996, verified=YES) — PI-controller-driven dynamic per-token probability threshold; explicitly proportional sparsity control.
Adding these makes the field even more crowded (≥6 close priors).

## Collision rating: **完全撞**
Score-gap-based K thinning is essentially the published Adaptive Gating + DA-MoE + DTop-p + SMIDT line. As a mechanism contribution, no novelty remains.

## Novelty space remaining
- *Byte-ROI* framing (not capacity / confidence): risky as sole differentiator
- Composition with drop (drop tokens × K_eff cuts experts per token)
- Empirical re-analysis of user's "K_eff hard truncation negative leverage"

## Conclusion: **放弃**
Post-GPT-QC verdict stronger: standalone fails. Adaptive Gating (2023) already covers the routing-side concept; DA-MoE / DTop-p cover variations. Salvage only as "byte-ROI-controlled action *inside D1-I4 controller*" — i.e., not a paper, an option in the action table.
