# Lit-check: D3-I4 — Workload-conditioned elastic replica pool (logical routing tag)

## Idea recap
Anchored vs elastic replica slots; per-session elastic claim via logical routing tag (O(1) table update); freed VRAM → KV.

## Keywords searched
- elastic expert replica per session online claim MoE serving 2024-2025
- ElasticMoE auto-scaling (D3 trace)

## Top candidates (all verified)
1. **ElasticMoE** (arXiv:2510.02613) — fine-grained zero-downtime scaling of MoE via HBM remap (Ascend NPU). Direct mechanism prior.
2. **MemServe** (arXiv:2406.17565) — elastic memory pool for KV in disaggregated serving.
3. **CRAFT** (arXiv:2603.28768) — cost-aware replica allocation; static.
4. **Lazarus** (arXiv:2407.04656, verified=YES this trace) — adaptive expert replica allocation; *training-side* (not inference).
5. **Matryoshka MoE** (arXiv:2509.26520, verified=YES this trace) — elastic inference-time expert *count* (not replica claim).
6. **Remoe** (arXiv:2512.18674, verified existence) — remote expert replicas in serverless inference.

## Closest 3 priors + differences
- **ElasticMoE** — direct mechanism prior (elastic + HBM remap). **Diff**: ElasticMoE = HBM-level (heavy); D3-I4 = logical routing tag (O(1), no weight move).
- **CRAFT** — static per-layer allocation. **Diff**: D3-I4 is per-session runtime claim.
- **Matryoshka MoE** — elastic expert count at inference. **Diff**: count vs replica claim; different operator.

## Has been published? **partial**
Elastic MoE replica / memory is multiply published; logical-routing-tag-only is differentiated. ElasticMoE is closest competitor.

## Collision rating: **接近但有差异 / 高风险**
GPT D3 QC already flagged "weakly distinguishable from DistServe-for-MoE + cache paging". Mechanism unit (logical tag) is the only differentiator.

## Conclusion: **需调整 / 降级**
Salvage: explicitly position as "logical-only elasticity unit + per-session arbitration" vs ElasticMoE's HBM-level. If user's hardware (8×RTX4090 PCIe) makes HBM remap impractical, D3-I4 is the *only* viable elastic path. As paper alone weak; as system component possible.
