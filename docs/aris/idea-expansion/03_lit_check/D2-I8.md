# Lit-check: D2-I8 — Decode-phase expert re-co-location

## Idea recap
Migrate the top-32 most-active experts to a "decode-host" rank per active session; eliminate dispatch a2a entirely for the active expert set.

## Keywords searched
- MoE decode expert co-location single rank migrate gather (this trace)
- expert offloading caching MoE inference
- decode-time expert relocation MoE

## Top candidates
1. **MoE-Infinity** (arXiv:2401.14361, verified=YES via D2 trace) — sparsity-aware expert cache with eviction; single-phase.
2. **DAOP** (arXiv:2501.10375, verified existence via search) — data-aware offloading + predictive pre-calculation one layer ahead.
3. **DuoServe-MoE** (arXiv:2509.07379) — dual-phase prefetch+cache.
4. **Pre-gated MoE** (ISCA'24, arXiv:2308.12066) — pre-gating with CPU offload of memory-hungry expert params.
5. **MoE-SpeQ** (arXiv:2511.14102, verified existence via D2 search) — speculative quantized decoding with proactive expert prefetching & offloading.
6. **Accelerating MoE Inference with Expert Sharding** (arXiv:2503.08467, partial verified) — tensor-sharding of expert matrices.

## Closest 3 priors + differences
- **DuoServe-MoE** — dual-phase MoE prefetch+cache. **Diff**: D2-I8 *migrates* active experts to a single rank vs DuoServe-MoE caching them in-place.
- **MoE-Infinity** — sparsity-aware caching. **Diff**: caching+eviction operator vs single-rank migration operator.
- **Pre-gated MoE** — CPU offload via pre-gating. **Diff**: CPU memory tier vs intra-GPU single-rank concentration.

## Has been published? **partial**
Offloading / caching / prefetching are multiply published. Active-expert migration to a single rank for decode is not directly published — adjacent but distinct operator.

## Collision rating: **接近但有差异**
Real adjacency on memory-tier management; specific operator (migrate-to-host-rank) is differentiated.

## Conclusion: **需调整**
Defensible only if migration overhead is explicitly characterized vs cache eviction (MoE-Infinity) and prefetch (DuoServe-MoE). Risk: if number of distinct active decode experts exceeds 32–50 in typical decode trace, the mechanism doesn't fit.
