## Closest 3 priors + differences
- **Fine-grained MoE LP** — direct competitor on *per-microbatch MoE granularity*. **Diff**: their objective is *load balance via LP token scheduling*; D3-I3 is *byte policy (drop kernel branch)* per microbatch. Different lever, same granularity. Hard differentiation; requires deep read.
- **Sarathi-Serve / Orca** — iteration-level scheduling, dense LLM. **Diff**: D3-I3 adds *MoE byte policy* at the same granularity.
- **MoE-Gen** — single-GPU module-based batching. **Diff**: not multi-rank EP; D3-I3 explicitly EP=8.

## Has been published? **partial / borderline**
